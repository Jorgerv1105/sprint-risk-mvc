# Sprint Risk MVC System

Sistema administrativo Scrum desarrollado con arquitectura MVC.

## Tecnologías

Frontend:

- SvelteKit
- SCSS
- BEM

Backend:

- Node.js
- Express
- MySQL

## Arquitectura

- Controllers
- Services
- Repositories
- Routes

## Funcionalidades

- Administración de tareas
- Relaciones entre tablas
- Dropdowns dinámicos
- Validación backend
- Evaluación de capcidad sprint
